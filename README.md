# 🐾 AdoptMe — Pet Adoption Page

> *"A gift of new life.."*

A warm and welcoming static web page built with **HTML** and **CSS** to help connect adorable pets with loving homes. Browse pet profiles, learn about their personalities, and take the first step toward adoption.

---

## 📸 Preview

![AdoptMe Screenshot](screenshot.png)

---

## ✨ Features

- 🐶 **Pet Profile Cards** — Each pet has a dedicated card with a photo, name, and personality description
- 🎨 **Clean UI** — Minimal black-and-white design with rounded card borders for a friendly look
- 📱 **Responsive Layout** — Cards arranged in a flexible grid that adapts to screen size
- 🔗 **Meet Links** — Clickable "Meet [Pet]" links styled as underlined anchors for easy navigation
- 🏷️ **Branding** — Custom site header (`adoptme.com`) and italic tagline at the footer

## 🚀 Getting Started

No build tools or dependencies needed — just open the file in your browser!

```bash
# 1. Clone the repository
git clone https://github.com/your-username/pet-adoption-page.git

# 2. Navigate into the folder
cd pet-adoption-page

# 3. Open in your browser
open index.html
# or simply double-click index.html in your file explorer
```

## 📌 How to Add a New Pet

1. Open `index.html`
2. Copy an existing pet `<div class="card">...</div>` block
3. Replace the image `src`, pet name, and description text
4. Save and refresh your browser — done! 🎉
